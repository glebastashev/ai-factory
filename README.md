# ai-factory

Три фронтенд-прототипа сайта ИИ-агентства Макса Люшера для сравнения дизайна первого экрана.

## Версии

1. [Карточки процесса](https://glebastashev.github.io/ai-factory/)
2. [Поток задач](https://glebastashev.github.io/ai-factory/version-2.html)
3. [ИИ-ядро и орбиты](https://glebastashev.github.io/ai-factory/version-3.html)

[Страница сравнения анимаций](https://glebastashev.github.io/ai-factory/animations.html).

Во всех версиях общие блоки, калькулятор эффекта в рублях и расчётные кейсы. Все формы отправляют заявку в `send.php` (папка `server/`): он сохраняет её на хостинге и пересылает в Telegram. На GitHub Pages сервера нет, поэтому там форма честно показывает «Заявка не ушла» и ссылку на Telegram.

## Разработка

React + Vite. Node.js 22.

```sh
npm ci
npm run dev
npm test
npm run build
```

Сборка находится в `dist/client`. GitHub Pages публикует папку `docs` из ветки `main`. Перед отправкой изменений выполните `npm run build:pages` и добавьте обновлённую папку `docs` в коммит.

Параметр `SITE_BASE_PATH` задаёт путь размещения сайта; для GitHub Pages команда `build:pages` использует `/ai-factory/`. По умолчанию используется `/`.

## Блок кейсов

Три вертикальные карточки в один ряд на компьютере. На планшете видны две карточки, на телефоне одна с горизонтальным пролистыванием и кнопками. Клик по карточке открывает описание процесса, скриншот системы и подробный расчёт. Показатели являются моделями на заданных вводных. Происхождение скриншотов описано в [case-screenshot-sources.md](case-screenshot-sources.md).

## Заявки в Telegram

`server/send.php` принимает заявки, отсекает ботов (скрытое поле, слишком быстрая отправка, не больше 5 заявок с адреса за 10 минут), сохраняет каждую заявку в `lead-data/leads.php` и отправляет её в Telegram. Если Telegram недоступен, заявка остаётся на хостинге и уходит командой `php send.php retry`.

Настройки лежат в `lead-config.php` на хостинге (образец `server/lead-config.example.php`). В репозиторий и в выгрузку настоящие настройки не попадают. Хостингу нужен PHP 7.4+ и доступ к api.telegram.org: 28.09.2026 он был у Beget и не был у REG.RU и большинства московских хостингов.
